# GarmentOS Cloud — وثيقة متطلبات المنتج (Product Requirements Document - PRD)

## 1. نظرة عامة
**GarmentOS Cloud** هو نظام ERP SaaS متكامل موجه لمصانع وورش الملابس (مع التركيز في المرحلة الأولى على ملابس الأطفال).
يدعم النظام كافة مراحل التشغيل من شراء وتوريد الخامات، وتخطيط الموديلات والـ BOM، وإدارة صالة القص ومراحل الخياطة، وإدارة المخازن المتعددة، والبيع المكتبي والجملة والتجزئة، والمتجر الإلكتروني المستقل، والمحاسبة الصناعية، والموارد البشرية وأجور القطعة.

## 2. الشرائح المستهدفة وأنماط التشغيل
1. **المصانع المنتجة لعلامتها التجارية الخاصة (Own-Brand Manufacturers):**
   - إنتاج وتوزيع وبيع المنتجات تحت اسم المصنع لمتاجر الجملة والتجزئة أو عبر المتجر الإلكتروني.
2. **مصانع تقديم خدمة القص للغير (Contract Cutting Rooms):**
   - استلام خامات العميل، فرش القماش وقصه، فرز الهالك، وتسليم الحزم للعميل مع إصدار فاتورة الخدمة.
3. **مصانع التشغيل والتصنيع للغير (CMT - Cut, Make, Trim Subcontractors):**
   - تصنيع كامل للغير بخامات العميل أو خامات المصنع وحساب مستحقات التشغيل.
4. **الورش المتخصصة الخارجية (Specialized Sub-workshops):**
   - ورش التطريز، الطباعة، المغاسل، وعمليات الأوفر والتشطيب.

## 3. المتطلبات غير الوظيفية الحاكمة
1. **أمان وعزل متعدد المستأجرين (Multi-Tenant Data Isolation):**
   - ضمان منع قراءة أو تعديل بيانات أي شركة بواسطة مستخدمي شركة أخرى عبر الـ APIs أو التقارير.
2. **الدقة الحسابية:**
   - منع استخدام Floating Point في البيانات المالية وأوزان وأطوال الخامات.
3. **التشغيل بدون اتصال بالإنترنت في صالة الإنتاج والبيع (Resilience):**
   - الحفاظ على كروت التشغيل الورقية المرمزة بالباركود لضمان استمرار العمل حتى في حال انقطاع الشبكة.
4. **ثنائية اللغة والاتجاه (Bilingual RTL/LTR):**
   - دعم كامل للغة العربية (واجهات RTL) والإنجليزية (LTR).
